 # CareerHub – Online Job Portal

CareerHub is a full-stack online job portal designed to connect job seekers with employers. Users can explore job opportunities, while employers can post jobs and manage applications.

## Features

* User registration and login
* Browse and search jobs
* Search jobs by keyword and location
* Employer job posting
* Employer dashboard
* Manage job applications

## Technology Stack

**Frontend**

* HTML
* CSS
* JavaScript

**Backend**

* Java
* Spring Boot
* REST API

**Database & Security**

* MySQL
* JWT Authentication
* BCrypt Password Hashing

## Project Structure

* `frontend/` – Frontend files
* `src/` – Spring Boot backend source code
* `pom.xml` – Maven dependencies and configuration
* `mvnw` and `mvnw.cmd` – Maven Wrapper scripts

## How to Run

### Frontend

Open the frontend's `index.html` file in a browser or use VS Code Live Server.

### Backend

1. Install Java and MySQL.
2. Create a MySQL database named `careerhub`.
3. Configure the database connection in `application.properties`.
4. Run the Spring Boot application using your IDE or Maven Wrapper.
