About the role

We are looking for a Frontend Developer to join our product engineering team. You will work closely with designers, backend engineers and product managers to build reliable and intuitive web experiences.

Responsibilities

  • Build responsive and accessible web interfaces.
  • Translate product and design requirements into high-quality frontend solutions.
  • Collaborate with backend engineers to integrate REST APIs and application services.
  • Identify and resolve performance and usability issues.
  • Write clean, reusable and maintainable code.
  • Participate in code reviews and technical discussions.

Requirements

  • Strong understanding of HTML, CSS and JavaScript.
  • Experience with React or another modern frontend framework.
  • Understanding of responsive web design.
  • Familiarity with REST APIs and Git.
  • Good problem-solving and communication skills.
